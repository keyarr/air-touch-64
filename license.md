# DEX provenance

I created the patched `classes.dex` used by this project for the Photoshop Touch ARM64 build. It is rebuilt from the AIR SDK shell and includes my Android inset fix; it is not the original `classes.dex` from Adobe's Photoshop Touch APK.

Adobe AIR runtime components in the DEX remain subject to the AIR SDK license. This notice applies only to my project changes and does not claim ownership of Adobe components.
